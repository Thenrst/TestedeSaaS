# TestedeSaaS

Projeto simples de SaaS para salvar anotações. O aplicativo possui backend em Node.js com Express e frontend em HTML/CSS/JavaScript.

## Executar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor:

```bash
npm start
```

3. Abra no navegador:

```text
http://localhost:3000
```

## Estrutura

- `server.js` - servidor Express e API de notas
- `public/` - frontend do aplicativo
- `data/notes.json` - armazenamento simples em JSON
